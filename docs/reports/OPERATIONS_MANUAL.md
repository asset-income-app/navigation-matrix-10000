# 系统运维手册

## 日常运维任务

### 1. 健康检查
- 每日4次自动检查（08:00, 12:00, 18:00, 22:00）
- 检查站点健康度和链接有效性
- 自动生成健康报告

### 2. 数据备份
- 每日凌晨2点自动备份
- 备份6个核心数据文件
- 备份目录：backups/daily_YYYY-MM-DD

### 3. 内容更新
- 每日10:00和14:00自动更新
- 处理793个站点数据
- 自动验证更新结果

## 监控运维

### 4. 性能监控
- 每1小时检查性能指标
- 监控加载时间、响应时间、压缩率
- 自动报警性能问题

### 5. 流量监控
- 每30分钟检查流量数据
- 监控流量趋势和异常
- 自动报警流量问题

### 6. 收入监控
- 每1小时检查收入数据
- 监控收入趋势和异常
- 自动报警收入问题
