# 广告管理器

## 功能概述
- 批量添加广告代码
- 管理广告位配置
- 统计广告收入
- 广告效果分析

## 广告位类型
| 位置 | 尺寸 | 价格 |
|------|------|------|
| 顶部横幅 | 728x90 | 1元/天 |
| 底部横幅 | 728x90 | 0.5元/天 |
| 侧边栏 | 300x250 | 0.3元/天 |
| 分类内 | 文字链 | 0.2元/天 |

## 使用方式
```
为所有站点添加百度联盟代码
查看广告位使用情况
统计本月广告收入
```
