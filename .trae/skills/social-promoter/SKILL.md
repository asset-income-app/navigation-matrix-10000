# 社交媒体推广器

## 功能概述
- 社交媒体账号管理
- 自动发布推广内容
- 分享按钮优化
- 社交引流分析

## 支持平台
| 平台 | 推广方式 | 效果 |
|------|----------|------|
| 微信 | 公众号/朋友圈 | 高转化 |
| 微博 | 账号推广 | 广传播 |
| 抖音 | 视频引流 | 高流量 |
| 小红书 | 内容分享 | 精准用户 |
| B站 | 视频推广 | 年轻用户 |

## 使用方式
```
生成社交媒体推广文案
优化站点分享按钮
分析社交引流效果
```

## 推广策略
- 定期发布优质内容
- 互动回复用户评论
- 热点话题借势推广
