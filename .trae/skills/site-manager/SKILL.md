# 站点管理器

## 功能概述

- 单站配置管理
- 商家收录管理
- 内容更新
- 分类管理
- 站点信息修改

## 调用时机

- 用户需要修改某个站点
- 商家付费收录
- 添加/删除分类
- 更新站点信息

## 核心操作

### 1. 查看站点信息
```
查看 {站点名} 的配置信息
```

### 2. 商家收录
```
在 {站点名} 的 {分类名} 中添加商家:
- 名称: {商家名称}
- URL: {商家网址}
- 描述: {商家描述}
```

### 3. 添加分类
```
给 {站点名} 添加新分类:
- 分类名: {分类名称}
- 图标: {emoji图标}
```

### 4. 更新站点信息
```
更新 {站点名} 的:
- 站点标题
- 站点描述
- 联系方式
```

### 5. 分类置顶
```
将 {站点名} 的 {商家名} 置顶到 {分类名} 第一位
```

## 商家收录流程

1. 用户告知商家信息
2. 读取站点 config.json
3. 在对应分类添加商家链接
4. 如果是付费收录，记录到 revenue-tracker
5. 重新生成该站点HTML
6. 部署更新

## 站点类型支持

| 站点类型 | 目录 | 配置字段 |
|----------|------|----------|
| 城市站 | 02-sites/cities/ | cityName, cityPinyin, province |
| 行业站 | 02-sites/niches/ | nicheName, nichePinyin, siteTitle |
| 组合站 | 02-sites/hybrids/ | cityName, nicheName |

## 使用示例

```
用户: 在北京站的教育分类添加学而思
AI调用: site-manager技能，更新 beijing/config.json，重新生成

用户: 把考研站的某商家置顶
AI调用: site-manager技能，调整链接顺序，重新生成

用户: 查看上海站的配置
AI调用: site-manager技能，显示 shanghai/config.json 内容
```

## 注意事项

- 修改后必须重新生成站点HTML
- 付费收录需记录到收入系统
- 置顶操作需确认付款状态
- 所有修改记录到操作日志
