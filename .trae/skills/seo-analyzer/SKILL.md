# SEO分析器

## 功能概述
- 检查SEO健康状态
- 分析搜索引擎收录
- 关键词排名追踪
- SEO优化建议

## 检查项目
| 项目 | 标准 | 说明 |
|------|------|------|
| sitemap | 存在 | 必须有sitemap.xml |
| robots | 存在 | 必须有robots.txt |
| meta标签 | 完整 | title/description/keywords |
| 内嵌数据 | 有 | 确保数据内嵌 |
| 响应速度 | <3秒 | 页面加载时间 |

## 使用方式
```
检查所有站点SEO状态
追踪考研站关键词排名
给出SEO优化建议
```
