# 任务调度器

## 功能概述
- 管理定时任务队列
- 每日/每周/每月任务调度
- 任务执行状态监控
- 任务失败自动重试

## 定时任务
| 任务 | 频率 | 说明 |
|------|------|------|
| 健康检查 | 每日 | 检查所有站点状态 |
| 链接检查 | 每周 | 检查链接有效性 |
| 数据备份 | 每日 | 自动备份项目 |
| 收入汇总 | 每日 | 统计收入数据 |
| SEO检查 | 每周 | 检查SEO状态 |

## 使用方式
```
查看今日任务
添加新定时任务
暂停某任务
```
