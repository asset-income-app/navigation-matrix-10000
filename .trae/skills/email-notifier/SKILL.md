# 件通知器

## 功能概述
- 重要事件邮件通知
- 定期报告邮件发送
- 异常预警邮件
- 商家收录确认邮件

## 通知类型
| 类型 | 触发条件 | 内容 |
|------|----------|------|
| 健康报告 | 每周 | 站点健康状态 |
| 收入报告 | 每月 | 收入汇总数据 |
| 异常预警 | 发现问题 | 问题详情+建议 |
| 商家确认 | 收录完成 | 收录凭证 |

## 使用方式
```
发送每周健康报告邮件
发送商家收录确认邮件
配置邮件通知规则
```
