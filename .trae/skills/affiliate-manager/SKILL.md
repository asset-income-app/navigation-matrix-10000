# 联盟返佣管理器

## 功能概述
- 管理联盟链接配置
- 统计返佣收入
- 管理合作伙伴
- 返佣数据分析

## 联盟平台
| 平台 | 返佣比例 | 类型 |
|------|----------|------|
| 淘宝联盟 | 2-10% | 电商 |
| 京东联盟 | 1-8% | 电商 |
| 课程分销 | 10-30% | 教育 |
| 旅游返佣 | 3-5% | 旅游 |

## 使用方式
```
为考研站添加课程分销链接
查看本月返佣收入
添加新的联盟合作伙伴
```
