# 合规检查器

## 功能概述
- 内容合规检查
- 敏感词检测
- 版权内容识别
- 广告合规审核
- 生成合规报告

## 检查项目
| 项目 | 标准 | 处理 |
|------|------|------|
| 敏感词 | 禁用词库 | 自动替换 |
| 版权内容 | 无侵权 | 标记删除 |
| 广告内容 | 合规文案 | 审核修改 |
| 外链安全 | 无恶意 | 移除风险链接 |

## 使用方式
```
检查所有站点内容合规性
扫描敏感词
审核广告内容合规
```

## 合规标准
- 遵守中国互联网法规
- 无违法违规内容
- 无侵权版权内容
- 广告内容真实合法
