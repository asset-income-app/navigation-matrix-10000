# 性能优化器

## 功能概述
- 页面加载速度优化
- CSS/JS代码压缩
- 图片资源优化
- 缓存策略优化

## 优化项目
| 项目 | 目标 | 方法 |
|------|------|------|
| 页面加载 | <2秒 | 代码压缩 |
| CSS大小 | <50KB | 去冗余 |
| JS大小 | <30KB | 压缩 |
| 总大小 | <200KB | 优化 |

## 使用方式
```
优化所有站点加载速度
压缩CSS/JS代码
检查站点性能报告
```
