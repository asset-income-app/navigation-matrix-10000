# 商家收录管理器

## 功能概述
- 记录商家收录信息
- 审核商家资质
- 管理收录到期续费
- 生成商家收录报告

## 收录流程
1. 商家提交申请
2. 审核商家资质
3. 确认付款
4. 添加到对应站点
5. 生成收录凭证

## 收费标准
| 服务 | 价格 | 期限 |
|------|------|------|
| 普通收录 | 300元 | 1年 |
| 分类置顶 | 500元 | 1月 |
| 首页推荐 | 2000元 | 1月 |

```
收录学而思到北京站教育分类(已付款300元)
查看北京站收录商家列表
提醒即将到期商家续费
```
